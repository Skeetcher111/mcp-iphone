## Проблема

Apple убирает из российского App Store приложения банков и сервисов. Удалили приложение с телефона, сменили iPhone или сбросили его, и обычным способом обратно уже не поставить: App Store его не показывает, хотя в покупках вашего Apple ID оно по-прежнему числится.

## Как это работает

1. Скачайте MCP iPhone и запустите на компьютере с Windows 10/11 или macOS 12 и новее.
2. Войдите под своим Apple ID (пароль от Apple ID, не код-пароль телефона) и подтвердите вход кодом на iPhone: вход идёт через сервер MCP iPhone.
3. Подключите iPhone кабелем.
4. Выберите приложение в списке, и оно встанет с оригинальной подписью Apple.
